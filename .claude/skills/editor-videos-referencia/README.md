# Editor de videos por referencia (skill para Claude Code)

Le enseñás a Claude cómo editás pasándole videos de referencia. Después le mandás tus crudos y los edita igual: corta las partes donde te repetís, pone subtítulos, títulos, imágenes, b-roll y capturas de tu web, y te devuelve el MP4 vertical listo.

## Instalación (2 minutos)
1. Descomprimí esta carpeta en `~/.claude/skills/` para que quede `~/.claude/skills/editor-videos-referencia/SKILL.md`.
2. Abrí Claude Code y escribí: **"editame este video"** o **"/editor-videos-referencia"**.
3. La primera vez revisa qué programas faltan y te ofrece instalarlos solo. Lo único que podés tener que hacer vos es poner la contraseña de la compu si hace falta Homebrew (en Mac).

## Cómo se usa
1. **Pasale 2 a 5 videos de referencia** y contale qué te gusta de cada uno. Arma un `ESTILO.md` con tu estilo y te lo muestra para que lo confirmes.
2. **Pasale tus crudos.** Edita uno, vos lo corregís, y cada corrección queda anotada para los siguientes.

Funciona mejor en Mac porque usa la conversión de Apple para los videos HDR del iPhone. En Windows y Linux también funciona.
